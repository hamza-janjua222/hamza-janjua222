**[E-Challan Management System](https://github.com/hamza-janjua222/e-challan-management-system)**
A C++ traffic violation management system built entirely on hand-implemented data structures — Hash Table, AVL Tree, Linked List, Queue, Stack, and Graph — coordinated together so a single real-world action (issuing a challan) correctly updates five structures in sync.

A neon-themed memory-matching game built with vanilla HTML, CSS, and JavaScript. Core logic — shuffling, match detection, timing — built from scratch, with keyboard accessibility and screen-reader support layered on top.
